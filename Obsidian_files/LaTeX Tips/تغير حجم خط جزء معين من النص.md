
### 1. استخدام الأوامر القياسية الجاهزة (Standard Commands)

يوفر **LaTeX** عشرة مستويات محددة مسبقاً لأحجام الخطوط، مرتبة من الأصغر إلى الأكبر:

- **للأحجام الكبيرة:** `\large`, `\Large`, `\LARGE`, `\huge`, `\Huge`.
- **للأحجام الصغيرة:** `\small`, `\footnotesize`, `\scriptsize`, `\tiny`.

**طريقة الاستخدام داخل النص:** يفضل دائماً وضع النص المراد تكبيره داخل "مجموعة" (Group) باستخدام الأقواس المجعدة `{ }` لحصر تأثير التكبير على هذا النص فقط [32، 67، 321].

```
هذا نص عادي، و { \Huge هذا نص ضخم جداً } بينما يعود النص هنا لحجمه الطبيعي.
% The braces { } limit the size change to the text inside them.
```

---

### 2. استخدام التكبير النسبي (حزمة `relsize`)

إذا كنت لا تريد تحديد حجم ثابت، بل تريد تكبير النص بمقدار "درجة" أو أكثر عن النص المحيط به، يمكنك استخدام حزمة `relsize`.

- `\textlarger{text}`: لتكبير النص بمقدار درجة واحدة.
- `\textlarger[n]{text}`: لتكبير النص بمقدار (n) درجة.

```tex
\usepackage{relsize} % Load the package in the Preamble

هذا نص عادي و
\textlarger{هذا نص أكبر بدرجة واحدة}
و 
\textlarger[2]{هذا أكبر بثلاث درجات}.
```

---

### 3. تحديد الحجم بدقة بالنقاط (Arbitrary Size)

إذا لم تكن الأحجام الجاهزة كافية، يمكنك استخدام الأمر **`\fontsize{size}{skip}\selectfont`** الذي تعلمناه سابقاً لتحديد أي حجم تريده بالنقاط (pt).

```
{ \fontsize{25}{30}\selectfont نص بحجم 25 نقطة }
% 25 is the font size, 30 is the line spacing (baseline skip).
```

---

### 4. التكبير الهندسي (حزمة `graphics`)

في بعض الحالات التصميمية، قد ترغب في تكبير النص كأنه "صورة" بنسبة معينة (مثلاً ضِعف الحجم الأصلي) بغض النظر عن قياسات الخط؛ هنا نستخدم `\scalebox` أو `\resizebox`.

```
\usepackage{graphics}

\scalebox{2}{نص مكبر مرتين هندسياً} % Scaled by a factor of 2
\resizebox{5cm}{!}{نص مضغوط ليمتد على عرض 5 سم} % Resized to a fixed width
```

### ملاحظة هامة:

عند استخدام أوامر مثل `\Huge` أو `\fontsize` داخل فقرة طويلة، تأكد من إنهاء الفقرة باستخدام أمر `\par` أو سطر فارغ قبل إغلاق القوس المجعد `{ }`؛ ذلك لأن **LaTeX** يحسب المسافة بين الأسطر بناءً على حجم الخط الموجود عند **نهاية الفقرة**.
