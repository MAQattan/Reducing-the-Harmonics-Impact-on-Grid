لزيادة التباعد بين السطور في مستند **LaTeX**، هناك عدة طرق احترافية توفرها المصادر، وأفضلها هو استخدام حزمة **`setspace`** لأنها تمنحك تحكماً دقيقاً وسهلاً.

إليك الطرق المتاحة لزيادة التباعد:

### 1. استخدام حزمة `setspace` (الطريقة الموصى بها)

تعتبر هذه الحزمة الأكثر مرونة، حيث تتيح لك تغيير التباعد للمستند كاملاً أو لأجزاء محددة منه.

أضف الأوامر التالية إلى **الديباجة (Preamble)**:

```
\usepackage{setspace} % Load the package for line spacing control

% Option A: Set predefined spacing for the whole document
\onehalfspacing % Sets 1.5 line spacing
% \doublespacing % Sets 2.0 line spacing

% Option B: Set a custom stretching factor
\setstretch{1.25} % Custom spacing (e.g., 1.25 times the normal spacing)
```

### 2. استخدام الأمر `\linespread`

يمكنك استخدام هذا الأمر مباشرة في الديباجة دون الحاجة لحزم إضافية، وهو يضرب المسافة الافتراضية في المعامل الذي تختاره.

```
\linespread{1.5} % Multiplies the default baseline skip by 1.5
```

### 3. تعديل `\baselinestretch` يدوياً

كانت هذه الطريقة مستخدمة في مشاريعك السابقة، وهي تؤدي نفس غرض `\linespread` 

```
\renewcommand{\baselinestretch}{1.5} % Change the standard baseline stretch globally
```

### 4. تغيير التباعد لفقرة محددة فقط

إذا كنت تريد زيادة التباعد في جزء معين من النص وليس كامل الملف، استخدم بيئة **`spacing`** التي توفرها حزمة `setspace` [312، 313].

```
\begin{spacing}{2.0} % Apply double spacing only to this block
هذا النص سيكون متباعداً بمقدار سطرين، بينما النص في بقية المستند سيبقى كما هو.
\end{spacing}
```

### ملاحظة هامة حول التنفيذ:

عند استخدام أمر تغيير التباعد مثل `\renewcommand{\baselinestretch}{..}`، قد لا تلاحظ التغيير فوراً إلا بعد تنفيذ أمر تغيير حجم الخط (مثل `\normalsize` أو `\small`) ليقوم **LaTeX** بإعادة حساب المسافات بناءً على القيم الجديدة. لذلك يفضل دائماً وضع هذه الأوامر في **الديباجة** قبل أمر `\begin{document}` لضمان تطبيقها على كامل العمل بشكل صحيح.
